# Homebrew Tap for tbmlib-cli (tbmlib.com)

Official Homebrew tap for **[tbmlib.com](https://tbmlib.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/tbmlib
brew install tbmlib-cli
```

## Quick Test

```bash
tbmlib-cli --help
```
